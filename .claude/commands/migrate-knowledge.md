# 지식 위키 마이그레이션

사용자가 `$ARGUMENTS`의 외부 리서치 산출물을 지식 위키에 통합하려 한다. 가능하면 Codex의 `migrate-knowledge` 스킬과 동일한 원칙을 따른다.

1. 대상 위키 루트를 확인하고 `Research-Vault/_wiki/WIKI-RULES.md`와 `INDEX.md`를 완전히 읽는다.
2. 원본은 읽기 전용으로 둔다. 이 명령의 기본 동작은 **copy-only**이며 원본 이동·삭제는 별도 승인 없이는 수행하지 않는다.
3. 포함·제외 manifest를 만들고, 포함 파일마다 상대경로·크기·SHA256을 기록한다. 코드·캐시·중간물·자격증명·비공개 원자료는 자동 제외한다.
4. `Research-Vault/Project-Knowledge/<project-slug>/`로 복사한 뒤 파일 수·경로·해시를 다시 검증한다. 충돌 파일을 덮어쓰지 않는다.
5. 복사 자료를 읽어 개념·Q&A·데이터 레지스트리에 통합한다. 사실·주장·추론·전망을 구분하고 수치의 단위·기간·지역·분모·방법을 기록한다.
6. 모순은 삭제하지 않고 병기한다. 더 강한 후속 합성이 앞선 합성을 대체할 때는 `SUPERSEDES`와 lifecycle metadata를 쓰며 날짜 원본 노트는 보존한다.
7. Git에서는 허용 경로만 명시적으로 stage한다. `git add -A`, 자동 rebase·stash·reset은 금지한다. 원격 경쟁이나 실패가 있으면 push하지 않는다.
8. 완료 시 manifest, 복사 검증, 갱신 페이지, lifecycle 변경, 미해결 질문, 커밋 해시를 보고하고 원본이 그대로 남아 있음을 확인한다.
